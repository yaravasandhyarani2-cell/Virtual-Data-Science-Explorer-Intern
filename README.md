## Quick Start & Build Pipeline
```bash
# Install dependencies
pip install -r requirements.txt

# Run complete automated build pipeline (generates diagrams & all 4 .docx reports)
python scripts/build_all.py
```

- `Week2_EDA_Visualization_Framework.docx` — Systematic EDA methodology, IQR outlier rules & data hygiene.
- `Week3_ML_Model_Plan.docx` — Leak-free Scikit-Learn pipelines, 5-Fold Stratified CV, tuning & MLOps serving.
- `Week4_Report_and_Presentation_Plan.docx` — Standalone final report, financial ROI, and SCR executive deck.
- `diagrams/` — 22 standalone publication-grade PNG diagrams (150+ DPI, unified palette).
- `scripts/` — Automated generators (`make_diagrams.py`, `build_week1-4.py`, `doc_helper.py`, `build_all.py`).
